# AWS-Azure-Cloud-Labs
Practical labs on cloud infrastructure deployment using AWS and Microsoft Azure.
## Overview
This repository showcases my practical experience in deploying and managing cloud resources. It includes labs from the AWS Academy and Microsoft Azure fundamentals coursework.

## Cloud Platforms and Services
- AWS: EC2 (Virtual Machines), S3 (Storage), IAM (Identity and Access Management), VPC (Networking).
- Microsoft Azure: Virtual Machines, Virtual Networks (VNet), Resource Groups, Azure Lab Services.
- Tools: Lucidchart (Architecture Diagrams), Remote Desktop (RDP), SSH.

## Lab Highlights

### Lab 1: AWS EC2 Deployment
- Launched and configured an EC2 instance (Linux).
- Configured Security Groups to allow SSH and HTTP traffic.
- Evidence: See aws_ec2_setup.png

### Lab 2: Azure Virtual Machine Setup
- Deployed a Windows Virtual Machine in Azure.
- Deployed a Linux Virtual Machine using Azure Lab Services (LinuxLab2024).
- Configured inbound port rules and networking settings.
- Evidence: See azure_vm_setup.png

### Lab 3: Network Architecture Design
- Designed a basic cloud network topology using Lucidchart, including subnets and gateways.
- Evidence: See network_diagram.png
